# #284: сохранение причины отказа после recovery

После неуспешной проверки здоровья recovery заменял исходную причину на `lease_expired`. Исправление сохраняет существующий `reason_code`; fallback применяется только к NULL. Fencing, срок lease, подтверждение остановки и активный маршрут не меняются.

## Статус

- Реализовано: одна SQL-правка в `confirm_stopped`.
- PostgreSQL regression до исправления: 2 failed, 1 passed; потеря `health_failed` и `probe_deadline` воспроизведена.
- После исправления: 19 recovery/active-cleanup тестов passed. Проверены health503, истечение probe deadline, crash без причины, отказ до истечения lease, stale proof и сохранение старого маршрута.
- Независимое ревью, CI и native worker replay ожидаются. Публикация и deployment не выполнялись.

Первые две попытки тестирования завершились setup errors Docker/Colima; они не считаются воспроизведением дефекта. Рабочая команда использует `DOCKER_HOST=unix:///Users/exzent/.colima/default/docker.sock`, `TESTCONTAINERS_RYUK_DISABLED=true` и существующее uv-окружение.
